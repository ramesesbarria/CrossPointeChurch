# CrossPointe Church — Official Website

The official website for CrossPointe Church Cebu. Built to help the congregation stay informed, connected, and equipped — and to welcome anyone who is exploring faith for the first time.

---

## About the Church

CrossPointe Church is a Spirit-filled, Christ-centered community located in the heart of Cebu City, Philippines. We exist to seek God, share life, and serve others.

- Location: One Central Hotel, Sanciangko Street, Cebu City, 6000
- Sunday Service: Every Sunday, 10:00 AM
- Email: crosspointecebu@gmail.com
- Facebook: https://web.facebook.com/crosspointechurchcebu
- Instagram: https://www.instagram.com/crosspointecebu
- Podcast: https://open.spotify.com/show/6UjCj47PE7wSv6hrvmerJL

## Technology Stack

- React
- Vite
- HTML
- CSS
- JavaScript
- React Router DOM
- Google Maps Embed API

## Development Setup

Requires Node.js v20 or higher.
```bash
npm install
npm run dev
npm run build
```
